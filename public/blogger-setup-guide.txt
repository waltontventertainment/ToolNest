TOOLZARO BLOGGER SEO, SITEMAP & ADSENSE CONFIGURATION GUIDE
=============================================================================

1. BLOGGER CUSTOM ROBOTS.TXT
-----------------------------------------------------------------------------
Where to paste:
Blogger Dashboard -> Settings -> Crawlers and indexing -> Enable custom robots.txt -> Custom robots.txt

Paste this exact content:

User-agent: Mediapartners-Google
Disallow:

User-agent: *
Disallow: /search
Allow: /

Sitemap: https://toolzaro.blogspot.com/atom.xml?redirect=false&start-index=1&max-results=500
Sitemap: https://toolzaro.blogspot.com/sitemap.xml


2. GOOGLE SEARCH CONSOLE SITEMAP SUBMISSIONS (Submit all 4)
-----------------------------------------------------------------------------
Where to submit:
Google Search Console -> Sitemaps -> Add a new sitemap

Submit each of the following 4 paths:
1) atom.xml?redirect=false&start-index=1&max-results=500
   (Indexes all 500 Blogger posts in Google)

2) feeds/posts/default?orderby=UPDATED
   (Tells Google to immediately re-crawl newly published and edited posts)

3) sitemap.xml
   (Standard XML sitemap index generated by Blogger)

4) sitemap-pages.xml
   (Indexes all static pages: About Us, Contact, Privacy Policy, Terms)


3. GOOGLE ADSENSE CUSTOM ADS.TXT
-----------------------------------------------------------------------------
Where to paste:
Blogger Dashboard -> Settings -> Monetization -> Enable custom ads.txt -> Custom ads.txt

Paste this exact line:

google.com, pub-8769496591745522, DIRECT, f08c47fec0942fa0


4. WHY TOOLZARO'S FLOATING BUTTON IS 100% ADSENSE-SAFE
-----------------------------------------------------------------------------
Google AdSense strictly forbids placing floating buttons near or over mobile sticky anchor ads.
Toolzaro positions the floating "Back to Top" button at bottom-20 (80px clearance from the bottom of the screen on mobile devices). This guarantees that users tapping "Back to Top" never accidentally tap sticky mobile anchor ads (which are 50-60px high at bottom-0).
Furthermore, an inline "Scroll to Top" button is provided directly inside the footer!
